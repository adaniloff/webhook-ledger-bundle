# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, no harassment or personal attacks. Disagree about code and ideas, not people.

Reports of unacceptable behavior can be sent through [GitHub Security Advisories](https://github.com/adaniloff/webhook-ledger-bundle/security/advisories/new) for this repository.
